# Video Transcoder

A cloud-based video transcoding pipeline built with **AWS ECS Fargate, Docker, and FFmpeg**.

## Features
- Processes videos in isolated Docker containers using AWS ECS Fargate.
- Supports 4 output formats.
- Uses Amazon S3 for source and output storage.
- Integrates Supabase for metadata management and playback URL tracking across 2 storage workflows.

## Tech Stack
AWS ECS, Fargate, Docker, FFmpeg, Amazon S3, Supabase.
